  quote were read again on 4 November 2026, and each reading now gives
  its day in one form. A page that refuses automated reading is quoted
  from the Internet Archive's newest capture, with the day of that
  capture. Where a page had changed, the documents now say what it says.

  the permission setting now starts on Auto on Pro, Max, Ultra and Team

  PRIVACY.md say so, and suggest Manual for participants' data.

  Ultra among them, which has no five-hour limit for verified accounts.
  TOOLS.md says that Claude Code keeps a text answer longer than 50,000

  on MCP in Claude Code now says.

  and its page on Codex from a phone in their new words. Codex's source
  was read at its release 0.166.0, and LM Studio's changelog up to

  a database in `~/.codex` as well as into its session files, and keeps
  the conversation's title and first message in a second one. So
  deleting the session files by hand leaves participants' words on the
  computer. PRIVACY.md, the README and the Terminal guide now name both
  databases, and PRIVACY.md suggests Codex's own command for deleting a
  conversation, which removes its files and its rows in both.
- Five claims about a named release of another program now name that
  release instead of a day. The writing guide, docs/WRITING.md, says in
  what form to write the day a claim was checked, and when a release's
  name may stand instead.
- Ten sentences that implied a later check or feature without a plan
  for it now say plainly what Exegete does not do, or what this project
  has not checked. Among them: Exegete does not nest an existing code
  under another code, and whether an update of the extension keeps a
  folder for projects chosen by hand has not been checked.
