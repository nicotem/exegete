### Documents

- The texts Exegete gives the assistant were read in full, as the
  documents were in 0.15.2: the descriptions of the tools this release
  does not otherwise change, the brief, the prompts, the resources, and
  the notes and refusals in the answers. The rest follow when those
  tools' changes are in.
- They no longer take every document for an interview. The rules on
  evidence speak of the same person or document; the rules for
  interviews apply to interviews. A coded passage can be "a whole
  paragraph or answer" long, and the examples vary.
- They no longer take it that you use QualCoder. A copy or a backup
  taken while another program is writing to the project holds what was
  last saved. Putting an existing code under another code is not in
  Exegete yet, and is done in QualCoder, if you use it.
- Untrue sentences were corrected. The export of coded segments said it
  follows a "File > Reports" menu, which QualCoder does not have: it
  follows the coding report, Code retrieval in QualCoder 4.0's Analysis
  menu. A merge of categories credited a note in the target's memo to
  QualCoder's development branch, though QualCoder 4.0 writes it.
  QualCoder's dialog for deleting a code gives the number of its
  sub-codes, not their names, and QualCoder 3.8.2 keeps its AI prompt
  library and chat history in the project's ai_data folder, as 4.0
  does. The tool that sets the AI coder name said Exegete compares code
  names as QualCoder 4.0 does. That holds of QualCoder 4.0's own
  assistant, for the letters A to Z only. QualCoder's dialogs compare
  code names letter for letter.
- Two texts say more about where your data goes. When the names list
  cannot be read, the advice after an import says that names given in a
  call reach the AI provider with the conversation. The tool that
  deletes a coding session says that a backup of the whole disk may
  still hold a copy.
- Capitals for emphasis, emoji and phrases such as "Perfect for" are
  gone from these texts, which call the person whose study it is "the
  researcher".
- Sentences that packed several facts together were split, one idea
  at a time, and words from Exegete's own code, such as "base tables",
  "echo" and "reparent", gave way to plain ones. The rules the texts
  state are the same.
