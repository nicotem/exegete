### Documents

- SUPPORT.md, CONTRIBUTING.md, the guide to choosing a project
  (PROJECT_SELECTION_GUIDE.md) and NOTICE were read in full, as the
  other documents were in 0.15.2. They no longer take it that you use
  QualCoder or that your documents are interviews, and their quips,
  emoji and exclamation marks are gone.
- SUPPORT.md says that an issue is public, so participants' data or a
  project put into one is published with it, and suggests a made-up
  example instead. It warns that Claude Desktop's log of Exegete keeps
  every request and every answer, the text of your documents included,
  so a log is best read before any of it goes into an issue. It also
  says that `exegete --version` gives the version as PyPI writes it,
  with "a0" for "-alpha", rather than giving one release as an example.
- SUPPORT.md also says that opening an issue needs a GitHub account,
  and that a line of the names file pairs a real name with its
  pseudonym, so a name is best described rather than copied. It warns
  that a sync service such as iCloud or OneDrive copies a project off
  the computer when it keeps the project's folder.
- The guide to choosing a project no longer shows sizes that Exegete
  does not give: the size in the listing is that of the project
  folder's own entry, not of its files. A project set in the
  configuration opens with the first tool that needs it, and Exegete
  stops at start when that project does not exist. A project missing
  from the list can be selected by its path. When no project was
  selected and one is set in the configuration, a selection that fails
  opens that project, and the guide now says so.
- CONTRIBUTING.md's untrue sentences were corrected. The MCP Inspector
  now starts with its own command, since `mcp dev` cannot load
  Exegete's server file. `docs/snapshot/` keeps the texts that are the
  same for every project, and no tool's answer but the brief. Three
  tools' texts and the brief give the lock paragraph's words, typed by
  hand, and CONTRIBUTING.md names each. The account of CI says
  what the comparison of the import's text, the documents job and the
  weekly watch also check. The facts check holds the map's Python files
  alone, and two opt-in scale tests share one build. The span walk is
  no longer given as copied code, since 0.15.1 removed it. The map says
  that the reading tool shows or opens a read-only copy of an original,
  never the original itself. What Zenodo, GitHub and PyPI say is now
  dated, read on 4 November 2026.
- CONTRIBUTING.md also names Exegete's reading folder beside
  `~/.exegete`, and says how to try the tools in the MCP Inspector on a
  made-up project, in an empty home folder. It says that on Windows
  onnxruntime makes a few usage reports as it loads, before Exegete can
  switch them off.
- NOTICE, in both packages, lists six (MIT), which EbookLib 0.20, the
  release in the lock, needs, and the libraries that lxml's packages
  contain. It calls the program Exegete throughout.
- The four documents were also read for plain words. Long sentences
  were split, and words a newcomer meets first, such as an issue, a
  lock file, a backup, a log and PyPI, are explained where they are
  used. In NOTICE, entry 73 points to entry 45, the one it describes,
  where it gave 44.
